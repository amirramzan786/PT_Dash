# 3. Recommended classes and candidate terms

## Class 9 — downloadable software / mobile app

### Candidate filing wording

> **Downloadable mobile applications for recording, managing, analysing and tracking workouts, exercise, physical fitness, nutrition, recovery and physical progress; downloadable software for recording, managing, analysing and tracking workout, exercise, fitness, nutrition, recovery and physical-progress data; downloadable software for creating, managing and following exercise and fitness programmes.**

### Why Class 9

Steel is distributed/used as software and a web/mobile application. Class 9 protects the downloadable software/app side of the brand.

### Keep out unless genuinely planned

Avoid adding unrelated hardware, wearables, medical devices or medical diagnostic software unless Steel genuinely intends to use the mark on those goods within the relevant five-year planning horizon.

---

## Class 41 — fitness/exercise information and programmes

### Candidate filing wording

> **Provision of online information relating to physical fitness and exercise; provision of exercise and fitness training information; provision of online exercise programmes; providing information relating to exercise training and physical fitness.**

### Why the wording is deliberately narrow

Class 41 is the area with the clearest known similarity risk because the preliminary search identified **STEEL PERFORMANCE SOLUTIONS** (`UK00801339667`) covering sports performance/coaching/training services.

For Project Steel, avoid unnecessarily broad Class 41 terms such as:

- personal trainer services;
- one-to-one fitness coaching;
- sports performance consultancy;
- gymnasium services;
- operation of fitness facilities;
- professional sports coaching;
- business training.

unless Steel genuinely launches those services and a fresh clearance review supports expansion.

The proposed wording focuses on information/programmes delivered through Steel rather than presenting the business as a sports-performance coaching consultancy.

---

## Class 42 — SaaS / non-downloadable platform

### Candidate filing wording

> **Software as a service [SaaS] featuring software for recording, managing, analysing and tracking workouts, exercise, physical fitness, nutrition, recovery and physical progress; providing temporary use of online non-downloadable software for recording, managing, analysing and tracking workout, exercise, fitness, nutrition, recovery and physical-progress data; hosting of software platforms for fitness, training, nutrition and progress tracking.**

### Why Class 42

This protects the hosted/non-downloadable SaaS platform aspect of Steel, complementing Class 9.

# 4. Classes not recommended at this stage

## Class 44 — health / nutrition / dietetic services

**Do not add by default.**

Steel currently needs protection as software plus fitness/exercise information. Class 44 should be reconsidered only if Steel begins providing actual personalised nutritional, dietetic, health or medical services rather than software tools and general information.

Adding unnecessary terms/classes increases cost and can increase the chance of conflict without providing useful protection.

## Clothing / merchandise classes

Do not add apparel/merchandise classes merely because Project Steel may one day sell branded clothing. File only if there is a credible commercial plan to use the mark on those goods within the relevant period.

# 5. UKIPO filing route and current fees

## Recommended: Right Start

Use **Right Start** because a similar Class 41 mark has already been identified and an early examination checkpoint is worth the modest extra cost.

For **3 classes** at current 2026 fees:

### Right Start

Initial examination stage:

- first class: £125
- Class 2: £30
- Class 3: £30
- **initial payment: £185**

If continuing after the report:

- second payment: **£185**
- **total if completed: £370**

### Standard filing comparison

- first class: £205
- two additional classes: £60 each
- **total: £325**

Right Start therefore costs **£45 more overall** for three classes if the application proceeds, but provides the examination checkpoint before the second payment.

Official source: https://www.gov.uk/how-to-register-a-trade-mark/start-your-application

# 6. Filing checklist

Before pressing submit:

- [ ] Confirm legal owner.
- [ ] Confirm owner address/contact details suitable for the application/public record.
- [ ] Confirm the mark is entered exactly as `PROJECT STEEL`.
- [ ] Select word mark, not logo/device mark.
- [ ] Run a fresh direct UKIPO search for `PROJECT STEEL` and close variants.
- [ ] Directly verify `STEEL PERFORMANCE SOLUTIONS` (`UK00801339667`) status, owner and exact Class 41 terms.
- [ ] Search close variants including `STEEL FITNESS`, `STEEL TRAINING`, `STEEL PERFORMANCE`, `STEEL HEALTH`, `STEEL COACH`, `PROJECT STEEL` and visually/phonically similar marks in Classes 9, 41 and 42.
- [ ] Ask the UKIPO Classification Team to confirm any uncertain custom wording.
- [ ] Keep evidence/screenshot/PDF of the final clearance search and date.
- [ ] Submit via Right Start.
- [ ] Diary the 28-day decision window after the Right Start report.
- [ ] If objections/similar marks are raised, assess before paying the continuation fee.

UKIPO classification guidance: https://www.gov.uk/guidance/how-to-classify-trade-marks

The UKIPO Classification Team currently lists `TMClassificationEnquiries@ipo.gov.uk` as a contact route for classification questions.

# 7. Expected registration lifecycle

A UK trade mark remains in force for **10 years** and can be renewed every 10 years.

At current 2026 fees, renewal for three classes would be:

- first class: £245
- two additional classes: £60 each
- **£365 every 10 years** at today's fee levels.

Future fees may change.

Official source: https://www.gov.uk/renew-your-trade-mark
